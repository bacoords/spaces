Explore AI in WordPress ↘

Use it with any AI coding agent. No existing site required.

Starter prompt Any AI agent 
Create a blank, persistent WordPress site for me on my computer using WordPress Playground CLI (@wp-playground/cli).

Work in a new, clearly named project directory and use the simplified start command:
npx @wp-playground/cli@latest start

Use the latest stable WordPress release and its default theme. Do not add sample content, plugins, themes, or custom code unless required to make the site run.

When the site is ready:
1. Confirm the dashboard and front end load.
2. Tell me the local URL and how to open the dashboard.
3. Tell me where the persistent site files live and how to start and stop the environment.
4. Summarize what you created, then wait for my next instruction.
