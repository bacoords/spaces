A practical route from old to new

Recommended sequence

Rebuild the system,
then rebuild the pages.

Start with the decisions that cascade through the whole store. Save one-off page adjustments for later.

  1. 01
    Back up and stage

    Take a full backup and do the entire migration on a staging copy.

  2. 02
    Set the visual foundation

    Recreate colors and typography in Global Styles first.

  3. 03
    Rebuild shared regions

    Move the header, footer, navigation, and sidebars into template parts.

  4. 04
    Compose commerce templates

    Adjust the catalog and product templates, then the homepage.

  5. 05
    Test the buying journey

    Check products, variations, cart, checkout, account, and mobile behavior.

  6. 06
    Cut over and monitor

    Switch the live theme only after staging passes the complete checklist.

!

This is a planner, not an automated migration.

Classic themes and block themes store design decisions differently. Always back up first, test in staging, and review custom PHP case by case. Storefront remains usable while you plan.
